# Archive

This directory keeps superseded report drafts and legacy tests for provenance. Nothing here is part of the supported workflow, and archived files may contain obsolete paths, assumptions, or claims.

The original FireScape repository state and its history remain available in the existing local checkout and on GitHub's [`archive/legacy-firescape`](https://github.com/alexandredunant/FireScape/tree/archive/legacy-firescape) branch. Large data, generated outputs, language-model files, and unrelated auto-research experiments were intentionally excluded from this focused publication package.
